# EventSphere

A Java-based event management system for planning, collaboration, and reporting.

## Project Overview
EventSphere helps manage events, venues, tasks, expenses, and participant flows for conferences, weddings, and sports events.

## Features
- Event lifecycle management
- Task tracking with priority scheduling
- Expense tracking
- Venue management
- Participant and registration support
- Reporting and dashboards
- Data structures for event scheduling and queues

## Tech Stack
- Java 17+
- Maven
- JDBC / SQL database
- JavaFX (FXML-based UI)

## Project Structure
See the repository tree for modules and data structure implementations.

## Getting Started
1. Clone the repository.
2. Run `mvn clean install`.
3. Start the app via `Main.java`.
