# EventSphere Project Proposal

## Objective
Build a JavaFX-based event management platform that supports planning, execution, and reporting for multiple event categories.

## Problem
Event organizers struggle with fragmented systems for scheduling, venue assignment, budgets, and participant management.

## Solution
Provide a centralized system with dashboards, task management, and reports.

## Scope
- User and role management
- Event and venue management
- Task scheduling and priority handling
- Budget and expense management
- Module-specific capabilities for weddings, conferences, and sports events
